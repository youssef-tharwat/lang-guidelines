# operator-overloads

Overload operators only for their mathematical or logical meaning.

**Why:** Operators carry expectations.

**Sources:** G:avoid-overloading-for-non-mathematical-purposes

---

## Avoid overloading for non-mathematical purposes (G:avoid-overloading-for-non-mathematical-purposes)

[Google Rust Style Guide](https://google.github.io/styleguide/rustguide.html#avoid-overloading-for-non-mathematical-purposes), CC BY 3.0.

Use operator overloads for their original mathematical/logical purpose, not just to make the code more concise (as “syntax sugar”).
